# Research Desk

공개 공시만으로 만든 크레딧·수주 대시보드. `site/` 를 정적 호스팅하면 끝이다.

```
./run.sh                 # 최근 14일치 갱신 + 재빌드
./run.sh 2025-01-01      # 전체 재수집

python3 cds/build.py --reuse   # 파싱 결과 재사용 (역산 로직만 손볼 때, 수 초)
```

CDS 파싱·역산은 852개 zip 전체를 훑어 1~2분 걸린다. 결과는 `cds/trades_cache.json` 에
남으므로, 집계 로직만 고칠 때는 `--reuse` 로 즉시 돌린다.

## 구성

```
cds/     DTCC 공개 스왑 공시 → CDS 스프레드 역산
  raw/     받아둔 zip (날짜별, 재실행 시 건너뜀)
  parse.py 공시 CSV 정규화
  price.py ISDA 표준모형 근사 프라이서
  build.py → site/data/cds.json
scripts/
  fetch_dtcc.sh  수집
  build_backlog.py  ~/backlog-bot/data.json → site/data/backlog.json

```

## CDS 를 어떻게 뽑았나

CDS 시세는 유료다. 대신 미국 규제상 **모든 스왑 체결은 실시간 공개 공시 대상**이라
DTCC 가 매일 CSV 로 푼다(`pddata.dtcc.com`, 인증 없음). 여기서 되돌린다.

표준화 이후 단일물 CDS 는 고정쿠폰(IG 100bp / HY 500bp)으로 거래하고 차액을 업프론트
현금으로 정산한다. 그래서 공시에 스프레드 칸은 비어 있고 `Other payment amount` 에
현금액만 남는다. 이걸 회수율 40% 가정으로 역산해 par spread 를 만든다.

함정이 셋 있었고 셋 다 실측으로 풀었다.

**노셔널 마스킹.** $5m 초과 거래는 `5,000,000+` 로 가려진다. 하한값을 쓰되, 노셔널이
그대로 공시된 소액 거래(한국물 174건)와 대조해 검증했다 — 5Y 중앙값 차이 0.5bp 이내.

**미수이자.** 공시 현금에 직전 IMM(3·6·9·12월 20일) 이후 경과쿠폰이 섞여 있다. 부호
규약이 공시에 없어, 한국물 700건으로 롤 전후 21일 구간의 동일만기 점프를 재서 정했다.

| 처리 | 롤 전후 점프 |
|---|---|
| 무시 | +6.4bp |
| 현금 + 미수 | +10.8bp |
| **현금 − 미수** | **+2.0bp** ← 채택 |

**업프론트 부호.** 누가 냈는지가 공시되지 않아 현금 하나에 해가 둘 붙는다(쿠폰보다 낮은
해 / 높은 해). 한쪽에서만 풀리는 거래의 비중으로 종목별 판정한다. 튀르키예는 90%가
한쪽에서만 풀려 명확하고, 이걸 적용하니 67bp → 215bp 로 제자리를 찾았다.

**검증.** 지수물(CDX·iTraxx)은 체결 스프레드가 공시에 직접 실려 역산이 필요 없다 —
기준선으로 쓴다. 국가별 서열(한국 < 일본 < 중국 < 필리핀 < 브라질 < 튀르키예)도
시장 통념과 맞는다.

**한계.** 호가가 아니라 체결이다. 한국물은 하루 1~3건이고 없는 날도 있다. 공식 종가와
다르며 수준·방향을 보는 용도다. 국내 기업 단일물은 체결이 훨씬 드물다.

## 회사채 스프레드

CDS 옆에 두는 두 번째 축. **CDS 와 정의가 달라 레벨을 맞대면 안 된다** — CDS 는 부도보험
요율이고 OAS 는 같은 만기 국채 대비 채권 수익률 차이다. 같은 지표끼리만 비교한다.

- **지수 OAS** — ICE BofA 등급별(AAA~CCC, 하이일드, 투자등급) 지수를 FRED CSV 로 받는다.
  인증 불필요. 시장 전체가 어디쯤인지 재는 기준선이다.
- **미 국채 금리곡선** — 재무부 일별 CSV. 인증 불필요.
- **개별 회사채 체결(FINRA TRACE)** — 미착수. `api.finra.org` 의 `fixedIncomeMarket`
  그룹은 401 이라 무료 계정 등록이 필요하다.

FRED 는 파이썬 기본 클라이언트로는 응답이 없고(타임아웃), curl 도 커스텀 User-Agent 를
붙이면 HTTP/2 스트림을 끊는다(exit 92). 기본 UA + `--http1.1` 로 받는다.

## 기업 분석 (티커 → 개요 + 재무제표)

정적 페이지라 브라우저가 DART·EDGAR 를 직접 못 부른다(CORS). 빌드 때 말아둔다.
검색 인덱스는 전 종목 한 파일, 상세는 종목당 한 파일로 쪼개 필요한 것만 받아가게 했다.

**국내** — DART 다중회사 주요계정. 100개사씩 받고 응답에 당기·전기·전전기가 함께 실려
40회 남짓 호출로 상장사 전체 6년치가 나온다. 개요(company.json)만 종목당 1회다.
이걸 한 번에 몰아 받다가 **IP 차단을 당했다**(응답 대신 소켓이 끊긴다, 1시간 이상 지속).
그래서 매출 큰 순으로 회차를 쪼개 받고, 캐시가 곧 진행률이다. `fill_profiles.py` 를
여러 번 돌리면 채워진다.

**미국** — EDGAR XBRL frames. companyfacts 는 한 곳당 3~5MB 라 1만 종목엔 못 쓴다.
frames 는 "개념 하나 × 기간 하나"를 전 종목에 대해 한 번에 주므로 170회로 덮는다.
다만 frames 는 역년(CY) 기준이라 두 부류가 샌다 — 5월 결산 오라클 같은 비역년 결산사와,
IFRS 로 내는 외국 발행사(EDGAR frames 에 `ifrs-full` 은 없다). 이 종목만 companyfacts 로
따로 보완한다(`backfill_us.py`).

빠지기 쉬운 함정 둘:
- 한 CIK 에 티커가 여럿 달린다(ORCL 과 ORCL-PD). CIK 로 덮어쓰면 우선주가 대표가 되어
  정작 ORCL 이 사라진다 — 접미사 없는 쪽을 대표로 두고 나머지는 별칭 파일로 쓴다.
- 외국 발행사는 USD 로 신고하지 않는다(TSM 은 TWD, 알리바바는 CNY). 통화를 함께 저장하고
  화면에도 띄운다.
